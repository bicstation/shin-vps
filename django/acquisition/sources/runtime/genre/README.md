# Genre Runtime

Responsibilities

- Resolve Product Genre
- Resolve Unified Genre
- Classify Product Reality

Input

- Primary Category
- Secondary Category
- Keywords
- Description

Output

- raw_genre
- unified_genre

Runtime Files

- universes.tsv
- aliases.tsv
- keywords.tsv
- negative_aliases.tsv

Authority

Genre Runtime is a Translation Runtime.

It converts observed product reality into
canonical genre identifiers.

It does NOT perform semantic analysis.
