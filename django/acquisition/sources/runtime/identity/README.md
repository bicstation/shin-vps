# SHIN CORE LINX
# Identity Runtime

## Purpose

This directory contains the Reality-based Identity Runtime dictionaries.

Identity Runtime is responsible for classifying product identity from
observed product information.

Examples:

- Maker
- Brand
- Series
- Collaboration
- Alias

These dictionaries are shared across all acquisition sources.

Examples:

- Official Manufacturer Sites
- LinkShare
- ValueCommerce
- Yahoo Shopping
- Amazon
- Future Import Sources

---

## Design Philosophy

Identity Runtime is **NOT AI**.

Identity Runtime is a deterministic classification runtime.

It does not generate or infer information.

Instead, it classifies observed Reality using TSV dictionaries.

Example:

Reality

Product Name

```
Dell Latitude 7450
```

↓

TSV

```
maker=dell
keyword=latitude
series=Latitude
```

↓

Result

```
Series = Latitude
```

---

## Why TSV?

Product identity is a Reality.

Manufacturers officially define:

- Brand
- Series
- Collaboration

Therefore these values should not be generated by AI.

Using TSV provides:

- Deterministic
- Reproducible
- Version Controllable
- Easy Maintenance

Adding a new product series only requires updating the TSV.

No code changes are necessary.

---

## Files

| File | Responsibility |
|------|----------------|
| makers.tsv | Manufacturer master |
| brands.tsv | Brand classification |
| series.tsv | Product series classification |
| collaborations.tsv | Collaboration classification |
| aliases.tsv | Alias normalization |
| negative_aliases.tsv | Excluded aliases |

---

## Responsibility

Identity Runtime MUST

- Classify Reality
- Normalize Identity
- Share identity dictionaries across acquisition runtimes

Identity Runtime MUST NOT

- AI Generation
- Semantic Analysis
- Product Recommendation
- Meaning Inference

Identity Runtime only classifies Reality.
